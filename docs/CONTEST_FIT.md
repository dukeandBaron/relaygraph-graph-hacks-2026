# Why this project fits Graph Hacks

Official references, read on 2026-10-18:

- https://www.wemakedevs.org/hackathons/falkordb
- https://www.wemakedevs.org/hackathons/falkordb/rules
- https://www.wemakedevs.org/hackathons/falkordb/schedule

Deadline: 2026-10-19 02:29 Asia/Shanghai (Oct 18 23:59 IST).

The new FalkorDB implementation is original event-period work. Earlier private
project experience informed the domain problem, but no old product is relabeled
as newly built. Required output is a public source repository, setup and graph
model documentation, central Cypher queries, a working demo video, and a stated
track. Local setup is allowed instead of live hosting. AI assistance must be
disclosed and the participant must personally understand and verify the work.

## Candidate decision

| Existing experience | Transferable idea | Decision |
|---|---|---|
| CoVerify / Same Page | Original notice, revisions, acknowledgements and receipts | Use domain experience; write a new graph implementation |
| RFQ / ProofQuote | Source-bound price calculations and exception review | Useful but exact arithmetic is already central; a graph migration is less direct for this short event |
| Competition intelligence | Source conflicts, deadlines and conservative recommendations | Broader source ingestion and rights review would add scope |
| VisionData Gate | Evidence gates, release dependencies and refusal paths | Learn its engineering discipline; do not copy its product or private materials |

Primary track: Agents That Act on Connected Data. Company Brain is a possible
secondary fit, not a claim of production company integration. Agent Memory and
Coordination is not selected: no invented autonomous coworkers, high-concurrency
claims or production identity system are needed for this prototype.

The graph performs dependency traversal, evidence retrieval, compare-and-set
adoption and persistent internal review action creation. Removing FalkorDB makes
those operations unavailable; there is no JSON/SQL substitute graph.

Prizes are the official stated hardware awards, not a guaranteed cash bounty.
Registration, final material acceptance and an award require actual platform
results, which are separate from local engineering tests.
